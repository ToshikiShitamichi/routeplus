# Route+

## プロダクト概要

Route+は、プログラミング学習者が自分のペースで課題を進められるステージ型の学習管理Webアプリです。

学習者は課題パックを選択して学習ロードマップに沿って進め、完了した課題をポートフォリオとして公開できます。学校は管理者として生徒の招待・進捗管理・独自課題の作成が可能で、組織単位での学習管理にも対応しています。

## 機能

### 学生（student）
- 課題パックの選択・追加
- 課題のステータス管理（未着手 / 進行中 / 完了）
- 課題の提出（プロダクト名・GitHub URL・デプロイURL）
- 提出済み課題一覧の確認
- ポートフォリオページの公開

### ゲスト（guest）
- 招待なしで登録
- 公開されている課題パックから自由に選択して学習

### 管理者（admin）
- 生徒の招待URL発行・グループ管理
- 生徒一覧・進捗詳細の確認
- 課題パックの作成・グループへの割り当て
- オリジナル課題の作成・編集・削除

### 運営（operator）
- 管理者アカウントの招待URL発行
- 管理者一覧の確認
- 公式課題の作成・編集・削除
